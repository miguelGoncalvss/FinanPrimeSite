Dúvidas Frequentes

Preciso pagar mensalidade?

A licença do FinanPrime é vitalícia (pagamento único): você paga uma vez e usa para sempre na versão adquirida. Mensalidade só existe se você contratar a Consultoria VIP, que é um serviço recorrente sob contrato (valores definidos conforme escopo).

Funciona no Mac ou Celular?

Atualmente é um software Desktop para Windows (focado em performance). A versão mobile está em desenvolvimento.

Meus dados ficam na nuvem?

Não. Prezamos pela sua privacidade total. O banco de dados fica criptografado apenas no seu computador (Local-First).

Integra com Google Agenda?

Sim. A agenda do sistema tem link direto para abrir/criar eventos no Google Agenda em 1 clique — perfeito para não perder prazos de cobrança, vencimentos e tarefas.

E se eu formatar o PC?

O sistema possui uma ferramenta de Backup simples. Basta salvar o arquivo .db no Google Drive e restaurar depois.
