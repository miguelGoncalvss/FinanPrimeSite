Dúvidas Frequentes

Preciso pagar mensalidade?

Não! O FinanPrime é venda de licença vitalícia (Lifetime). Você paga uma vez e usa para sempre na versão adquirida.

Funciona no Mac ou Celular?

Atualmente é um software Desktop para Windows (focado em performance). A versão mobile está em desenvolvimento.

Meus dados ficam na nuvem?

Não. Prezamos pela sua privacidade total. O banco de dados fica criptografado apenas no seu computador (Local-First).

E se eu formatar o PC?

O sistema possui uma ferramenta de Backup simples. Basta salvar o arquivo .db no Google Drive e restaurar depois.
